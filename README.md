# ALPINGEO — sito marketing

Sito statico Astro per **ALPINGEO Engineering S.r.l.** (ingegneria geotecnica, Bolzano / Alto Adige).

## Pagine

- `/` Home
- `/chi-siamo`
- `/servizi`
- `/contatti`
- `/privacy`

## Sviluppo

```bash
npm install
npm run dev
```

Build di produzione:

```bash
npm run build
npm run preview
```

Output: `dist/` (pronto per Vercel / hosting statico).
